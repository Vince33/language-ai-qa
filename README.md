# language-ai-qa
A portfolio project exploring AI Quality Engineering for indigenous
and endangered language technology.

## What this is
An evaluation framework for AI systems that attempt to handle indigenous
and endangered language content. The focus is on building tooling that
helps experts assess whether AI models are behaving responsibly —
not just relevantly — when working with low-resource language data.

## Why this niche
Generic AI evaluation metrics measure relevancy. But for indigenous and
endangered languages, relevancy is not enough. A model that confidently
fabricates vocabulary causes more harm than one that admits uncertainty.
This project explores what responsible AI evaluation looks like in that
context.

## Motivation
Puerto Rican descent with personal interest in Taíno cultural recovery. 
Building evaluation tooling for a domain I care about getting right.
